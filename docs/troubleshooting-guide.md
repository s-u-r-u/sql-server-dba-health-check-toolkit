# Troubleshooting Guide

## Database not ONLINE
Check database state, recent errors, recovery progress and storage.

## Backup is old
Check SQL Agent job status, backup destination availability, permissions and SQL Server error logs.

## Blocking detected
Identify the lead blocker, inspect the SQL statement, transaction age and application behavior before taking action.

## Long-running query
Review execution plan, waits, CPU, reads, indexes, statistics and parameter behavior.

## High fragmentation
Consider workload, page count and maintenance policy before rebuilding or reorganizing.

## Always On unhealthy
Check replica connectivity, synchronization state, log send queue, redo queue and SQL Server error logs.
